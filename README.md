## Contexte du projet

HRNet est un projet fictif, constituant le 10ème projet pratique dans le cadre du cursus que je suis chez OpenClassrooms. <br />
Celui-ci m'a amené à travailler sur :

- La "conversion" d'un plugin jQuery en composant fonctionnel React
- La refonte d'une application pour réduire la dette technique
- La production de documentation technique pour une application React
- L'analyse de la performance d'une application web
